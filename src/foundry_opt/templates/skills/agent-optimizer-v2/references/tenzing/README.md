# Pinned Tenzing source

This directory contains the locally readable source needed to verify
methodology alignment.

- `SOURCE_MANIFEST.yaml` identifies the upstream repository, commit, file
  identities, normalized hashes, and required reading.
- `climb.md` is an unmodified snapshot of the normative loop at the pinned
  commit.
- `LICENSE` is the upstream license from the same commit.

Do not edit the snapshot to adapt agent optimization. Agent-specific execution
guidance belongs in `../../guides/loop.md`. Updating the source requires a new commit
pin and verified source identities.
